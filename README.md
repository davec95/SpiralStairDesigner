# Deer Park Spiral Staircase Project

This project contains tools and resources for the IRC spiral staircase headroom calculator.

## Overview

The Spiral Staircase Project includes:

- **Spiral Stair Designer HTML** - A client-side calculator for verifying headroom, going dimensions, and IRC compliance for spiral staircases
- **CAD Outputs** - FreeCAD-generated 3D models and step-by-step construction guides

## Files

### Calculator
- `SpiralStairDesigner.html` - Interactive spiral staircase headroom calculator (run locally or hosted)

### Documentation & Resources
- `spiral-designs/` - Directory containing CAD outputs and construction guides

## How to Use

### Local Installation
1. Download `SpiralStairDesigner.html`
2. Open in any modern web browser (no server required)
3. Adjust parameters to verify your staircase design

### Online Access
Visit the hosted version at: https://davec95.github.io/SpiralStairDesigner/

## Technical Details

The calculator implements:
- IRC R311.7.2 minimum headroom (78" / 6'8")
- IRC R311.7.10.1 spiral staircase requirements
- Walkline analysis (12" from pole edge)
- Going and plate depth calculations
- Platform/landing overlap detection
